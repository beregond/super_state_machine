============
Installation
============

Super State Machine supports Python 3.10 to 3.14 and has no runtime
dependencies.

Install it from PyPI::

    $ pip install super-state-machine

Or, to keep it isolated in a virtual environment::

    $ python -m venv .venv
    $ source .venv/bin/activate
    $ pip install super-state-machine

With `uv <https://docs.astral.sh/uv/>`_::

    $ uv add super-state-machine

To work on Super State Machine itself, see :doc:`contributing`.
